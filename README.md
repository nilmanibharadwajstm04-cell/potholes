# RoadGuard - Automated Pothole Intelligence

RoadGuard is an automated civic road intelligence system that detects potholes using YOLOv8, extracts GPS coordinates, and clusters reports using DBSCAN to identify critical zones for municipal repair.

## How to Get Your Free Public URL for Judges (3-Click Guide)

1. Create a new repository on [GitHub](https://github.com/new) named `roadguard`.
2. Upload the files in this directory to your repository.
3. Go to [share.streamlit.io](https://share.streamlit.io) and sign in with your GitHub.
4. Click **New app**, select `roadguard`, set main file path to `app.py`, and click **Deploy**.
5. Within 2 minutes, Streamlit will give you your permanent free public URL (e.g. `https://roadguard.streamlit.app`)!
